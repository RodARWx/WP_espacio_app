# ESPACIO Desktop Wrapper (Windows / macOS / Linux)

- **Owner Role:** Frontend
- **Tech Stack:** Electron 33 + OS safeStorage
- **Workspace Dependencies:** `apps/shell`, `@espacio/auth-store`
- **Related Jira Tickets:** `GPWP-20, GPWP-22, GPWP-24`

## Responsibility
Desktop shell wrapping `apps/shell` build for wide-screen side-by-side property comparison, encrypted refresh-token storage (`safeStorage`), and native PDF invoice printing/export.
